Módulos del curso

Tres temas para construir páginas bien hechas.

Módulo 1

HTML semántico

Usar la etiqueta correcta para cada contenido ayuda a los buscadores y a los lectores de pantalla a entender la página.

Leer más sobre HTML semántico (se abre en una pestaña nueva)

Módulo 2

Accesibilidad web

Textos alternativos, etiquetas en los formularios, buen contraste y navegación completa con teclado.

Leer más sobre accesibilidad web (se abre en una pestaña nueva)

Módulo 3

Estilos con CSS

Variables, Grid y Flexbox para crear diseños ordenados que se adaptan a cualquier pantalla.

Leer más sobre CSS (se abre en una pestaña nueva)
